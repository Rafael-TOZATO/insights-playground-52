# Insights Playground

Ecossistema analítico interativo em React e TypeScript para inteligência comercial, gestão estratégica e visualização avançada de KPIs de vendas, estruturado com padrão corporativo e integrado ao portfólio de engenharia de dados[cite: 11].

## Estrutura do Repositório

* `src/` e `public/`: Aplicação web interativa em React, TypeScript e Vite com visualização de KPIs de vendas e gestão estratégica[cite: 11].
* `atlas-vendas.csv`: Dataset base de vendas (`Atlas - Dashboard`) utilizado para análises e visualização[cite: 11].
* `banner_insights_playground.jpg`: Banner visual do projeto[cite: 11].
* `AGENTS.md` e `roadmap.md`: Diretrizes de agentes e roteiro de evolução do projeto[cite: 11].
* `package.json`, `bun.lock` e `vite.config.ts`: Dependências, scripts e configuração de build/execução[cite: 11].

## Como Executar

1. Instale as dependências com `bun install` (ou `npm install`) e inicie o ambiente com `bun run dev` (ou `npm run dev`) conforme `package.json`[cite: 11].
2. Acesse a aplicação local exibida no terminal para explorar os KPIs de vendas e painéis interativos sobre `atlas-vendas.csv`[cite: 11].

## Entrega Esperada

* Painéis interativos de inteligência comercial e gestão estratégica com KPIs de vendas[cite: 11].
* Base analítica pronta para demonstração e adaptação a novos conjuntos de dados tabulares no mesmo esquema.
